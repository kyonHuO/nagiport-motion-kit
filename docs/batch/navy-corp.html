NAGIPORT MOTION KIT / 白紺・業務向け案

業務のサイトで、迷いのない動き方。

派手さを抑え、読みやすく、信頼感のある動き方だけを盛り込んだ1ページのサイトテンプレートです。日本語の行間で崩れにくい作りで、文言と画像を差し替えて使う形を想定しています（検証中）。

02 / FEATURES

できること

業務のサイトで本当に必要とされる動きだけを選んだ、3つの方向です。

A

見出しが読める動き方

スクロールに合わせて見出しが静かに立ち上がる動き。強調しすぎず、目線の誘導だけに使います。

B

表が崩れない構成

料金表・比較表は幅が狭くなっても横スクロールで対応。日本語の長いセルでも折り返しが乱れません。

C

動きを止められる

OSで「アニメーションを減らす」を選ぶと、すべての動きが消えます。利用者の設定を尊重する作りです。

04 / FAQ

よくある質問（案）

サーバーの準備は必要ですか？

想定しているのはファイルを置いて公開するだけの形です。特別なサーバー機能は使っていません（検証中）。

動きを全部消せますか？

OS側の「アニメーションを減らす」設定を選ぶと、すべての動きが消えて通常の見やすいページになります。

差し替えた後、壊れたら？

保証の範囲はまだ確定していません。差し替えで起きた不具合の対応範囲は検討中です。
