# 量産バッチ（docs/batch/）

2026-10-20、纺が別ディレクトリに量産した販売ページ案。Jervisの既存3ページ（docs/variants/）と9ページ、以及34テンプレート（docs/templates/）には手を付けず、ここだけで量産する分担。

## このバッチのねらい
- 次バッチ案の「白紺・業務向け（主案）」「暖色・相談窓口（比較用1案）」を実ページに落とす。
- Frikの指摘通り、比較用に**文章と機能を揃え、配色と雰囲気だけ変える**構成にする。
- すべて noindex の検討中デモ。文言・料金・提供内容は案。

## 揃えた点（比較のため）
- セクション構成: 概要（確認済み/未確定の表）→ できること(3) → プラン(2) → FAQ(3)
- 文言は白紺・暖色で同一。配色・角丸・マークの形だけを変える。
- prefers-reduced-motion 対応・スキップリンク・日本語折り返し・表の横スクロールは全ページ共通。
